# Backend Onboarding — ZeeFrame

> Цель: научить нового бэкендера **читать чужой код**, понимать слои, флоу и **принятые решения (WHY)**.
> Скоуп: только `backend/` (+ ссылки на `docs/ARCHITECTURE.md` и ADR). Фронтенд не трогаем.

## Как пользоваться (ты — ученик)

1. Прочитай [01-CURRICULUM.md](./01-CURRICULUM.md) — порядок погружения.
2. Дождись (или запусти) агентов по [00-ORCHESTRATION.md](./00-ORCHESTRATION.md).
3. Читай готовые гайды в `guides/` **строго по порядку номеров**.
4. После каждого гайда ответь на вопросы из [CHECKPOINTS.md](./CHECKPOINTS.md) (вслух или письменно).
5. Не пропускай шаг «открой файл и проследи вызов» — цель не выучить текст гайда, а **научиться ходить по коду**.

## Как пользоваться (ты — раздаёшь агентам)

1. Открой [00-ORCHESTRATION.md](./00-ORCHESTRATION.md).
2. Скопируй целиком соответствующий файл из `agents/A*.md` в чат агента.
3. Соблюдай порядок зависимостей (параллель где указано).
4. Принимай результат только если выполнен DoD в промпте агента.
5. После A0–A8 запусти A9 (синтез).

## Карта артефактов

| Путь | Назначение |
|------|------------|
| `00-ORCHESTRATION.md` | Мета-план: антигаллюцинации, порядок агентов, приёмка |
| `01-CURRICULUM.md` | Пошаговый путь ученика |
| `CHECKPOINTS.md` | Контрольные вопросы «понял ли?» |
| `agents/A*.md` | Готовые промпты для агентов-авторов гайдов |
| `guides/` | Готовые обучающие материалы (пишут агенты) |

## Источники истины (не выдумывать)

- Код: `backend/app/**`, `backend/alembic/**`, `backend/tests/**`, `backend/scripts/**`
- Архитектура: `docs/ARCHITECTURE.md`
- ADR: `docs/adr/003-modular-monolith.md`, `docs/adr/domain-vocabulary.md`, `backend/docs/adr/001-datetime-and-studio-timezone.md`
- Конфиг зависимостей модулей: `backend/pyproject.toml` (`import-linter`)

## Правило качества

Если в гайде нет **пути к файлу + имени символа** — утверждение считается неподтверждённым.
Если чего-то нет в коде/ADR — писать `UNKNOWN` и открытый вопрос, а не угадывать.
